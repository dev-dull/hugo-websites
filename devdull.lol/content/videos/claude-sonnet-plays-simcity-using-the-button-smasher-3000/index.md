## Description
Claude Sonnet 5.5 is going to play SimCity on a (clone) SNES: an actual console, an actual cartridge, and an actual controller with its buttons pressed by the Button Smasher 3000 which is a Raspberry Pi 4, a breadboard, and twelve transistors wired up to the inside of a SNES pad.

Claude Sonnet looks at the screen, decides what to do, uses the Pi's GPIO pins to "press" the buttons on the controller, and narrates using Kokoro text-to-speech.
